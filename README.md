# ひと息タイマー

実際に作業した時間を記録する、日本語の個人用タイマーです。

## 使い方

HTTPSで配信した `index.html` をSafariで開き、カテゴリを選んで「作業開始」を押します。「一時停止」「再開」「終了して保存」で操作できます。「ストレッチ＆運動」で元の作業を止め、運動だけを別記録として保存できます。

Safariの共有メニューから「ホーム画面に追加」を行い、日常の記録は追加したアイコンから起動して使ってください。

## 記録の保存

記録は利用する端末のブラウザ内に保存されます。外部データベースや端末間の同期はありません。定期的に「バックアップを保存」でJSONを保存してください。「JSONから復元」で追加復元できます。ブラウザのデータ消去やアプリ削除の前にもバックアップが必要です。

記録JSONやメモをこのリポジトリへ追加しないでください。公開するのはアプリ本体だけです。

## 更新時の注意

配信URLと保存キー `worktimer.v1` を維持してください。保存形式を変更する場合は旧データを引き継ぎます。アプリ本体を更新するときは `sw.js` のキャッシュ番号も更新します。更新前に記録をバックアップし、作業を保存してアプリを閉じてから開き直してください。
